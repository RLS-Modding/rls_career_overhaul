How to Run a Dyno Pull
  1. Start the engine.
  2. Select a high forward gear suited to the vehicle—typically 3rd or 4th—and keep it in that gear.
  3. Press Arm Pull. Hold the selected gear steady for a moment.
  4. Apply at least 90% throttle. Recording starts automatically.
  5. Hold the same gear and throttle through the pull. Lift below 75% throttle to finish.

Avoid shifting or braking while recording; either will be reported in the pull warnings.
