# Security

## Report a vulnerability privately

Use [GitHub's private vulnerability report form](https://github.com/RLS-Modding/rls_career_overhaul/security/advisories/new) for a suspected security vulnerability in RLS Career Overhaul or its repository tooling. Avoid posting exploit details in a public issue while the report is being assessed.

Include:

- The affected Overhaul and BeamNG versions, platform and relevant component.
- Steps or a small example that demonstrates the problem.
- The expected security impact and any conditions needed to trigger it.

Remove passwords, tokens and unrelated personal information from attachments. We will review the report and coordinate fixes and disclosure through the private advisory.

## Versions

We prioritize the latest public release and maintained development code. Reports affecting older releases are welcome; identify the affected version so we can check whether the issue remains present.

## Gameplay bugs and support

Use [Issues](https://github.com/RLS-Modding/rls_career_overhaul/issues) for gameplay bugs, loading problems and feature requests. See [Troubleshooting](https://github.com/RLS-Modding/rls_career_overhaul/wiki/Troubleshooting) for setup help.
