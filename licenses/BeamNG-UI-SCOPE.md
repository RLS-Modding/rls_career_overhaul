# BeamNG UI attribution scope

The following files contain adaptations of BeamNG UI source. Preserve the
upstream copyright and permission text in [BeamNG-UI-MIT.txt](BeamNG-UI-MIT.txt).
That text is copied unchanged from the installed BeamNG `ui/LICENSE`.
RLS Modding contributed the Overhaul adaptations; these files are outside
the exclusive original-RLS AGPL grant. Existing file notices remain in effect.

The upstream heading names HTML, images, JavaScript and CSS throughout the
UI tree. This inventory also identifies Vue and SCSS adaptations of that
UI source; it preserves the supplied text without expanding its wording or
replacing it with an unqualified whole-file license declaration.
